# Параметрический стол для nanoCAD BIM Строительство

Учебный проект по разработке параметрического объекта для **nanoCAD BIM Строительство** с использованием **C#** и **nBIM SDK / ParametricKit**.

Проект выполнен в рамках повышения квалификации и демонстрирует создание собственного параметрического 3D-объекта — стола, геометрия и параметры которого могут изменяться непосредственно в nanoCAD с помощью параметрических ручек (Grips).

Репозиторий: https://github.com/Svetlana3178/Table

---

## Возможности

В текущей версии проекта реализованы:

* создание параметрического стола;
* выбор точки вставки объекта непосредственно в nanoCAD;
* изменение длины столешницы с помощью `LengthGrip`;
* изменение ширины столешницы с помощью `LengthGrip`;
* изменение толщины столешницы с помощью `LengthGrip`;
* изменение общей высоты стола с помощью `LengthGrip`;
* изменение размера сечения ножек с помощью `LengthGrip`;
* изменение положения ножек по двум направлениям с помощью `OffsetGrip`;
* переключение типа сечения ножек между круглым и квадратным с помощью `SwitchGrip`.

Все основные размеры связаны с параметрами объекта, поэтому изменение параметров приводит к перестроению геометрии параметрического объекта.

## Принцип работы

Параметрический стол состоит из нескольких частей:

```text
Table
│
├── TableSpecification
│   ├── размеры столешницы
│   ├── высота стола
│   ├── размеры ножек
│   ├── положение ножек
│   ├── координаты точки вставки
│   └── тип сечения ножек
│
└── TableView3D
    ├── столешница
    ├── ножка 1
    ├── ножка 2
    ├── ножка 3
    ├── ножка 4
    │
    └── Parametric Grips
        ├── LengthGrip
        ├── OffsetGrip
        └── SwitchGrip
```

Параметры хранятся в `TableSpecification`, а `TableView3D` использует эти параметры для формирования геометрии.

## Параметры объекта

В объекте используются параметры, отвечающие за положение, размеры и конфигурацию стола.

### Точка вставки

```text
PointX
PointY
PointZ
```

Эти параметры определяют координаты точки вставки параметрического объекта.

При выполнении команды создания стола пользователь указывает точку в графической области nanoCAD.

---

### Размеры столешницы

```text
LengthTop
WidghtTop
ThickTop
```

Параметры определяют:

* длину столешницы;
* ширину столешницы;
* толщину столешницы.

---

### Высота стола

```text
HeighTable
```

Определяет общую высоту стола.

Высота ножек рассчитывается с учётом толщины столешницы:

```text
Высота ножки = Высота стола − Толщина столешницы
```

---

### Размер ножек

```text
TableLegSizeCross
```

Определяет размер сечения ножки.

Для круглой ножки параметр используется для расчёта радиуса цилиндра:

```text
Radius = TableLegSizeCross / 2
```

---

### Положение ножек

Положение ножек задаётся параметрами:

```text
TableLegCrossX
TableLegCrossY
```

Они позволяют задавать отступы ножек от краёв столешницы.

---

### Тип сечения ножек

Для переключения типа ножек используется параметр:

```text
CheckLegs
```

Переключение выполняется с помощью `SwitchGrip`.

Доступны два варианта:

```text
Круглое сечение
Квадратное сечение
```

При переключении изменяется отображаемая геометрия ножек.

## Параметрические ручки

Одной из основных целей проекта является демонстрация работы параметрических ручек `ParametricKit`.

### LengthGrip

`LengthGrip` используется для изменения линейных размеров объекта.

В проекте с его помощью изменяются:

* длина столешницы;
* ширина столешницы;
* толщина столешницы;
* высота стола;
* размер сечения ножки.

Каждая ручка связана с соответствующим параметром через `Assignment`.

Принцип связи:

```text
LengthGrip
    │
    └── Assignment
            │
            ▼
    SpecificationParameter
            │
            ▼
        Геометрия
```

---

### OffsetGrip

`OffsetGrip` используется для изменения положения ножек.

Он позволяет перемещать ножку относительно основных размеров столешницы по двум направлениям.

Таким образом, положение ножек определяется параметрами, а не фиксированными координатами.

---

### SwitchGrip

`SwitchGrip` используется для переключения вариантов геометрии.

В проекте он отвечает за выбор типа сечения ножки:

```text
┌─────────────────────┐
│ Сечение ножки       │
├─────────────────────┤
│ ○ Круглое           │
│ □ Квадратное        │
└─────────────────────┘
```

Выбранное значение записывается в параметр объекта через:

```csharp
Assignment = Entity.Specification.CheckLegs
```

## Создание объекта

Для создания стола используется команда:

```text
NSC_TABLE
```

После запуска команды пользователь указывает точку вставки объекта.

Далее создаётся `TableSpecification`, в которую передаются координаты выбранной точки:

```csharp
specification.PointX = insertPoint.X;
specification.PointY = insertPoint.Y;
specification.PointZ = insertPoint.Z;
```

На основании спецификации формируется параметрический объект.

После этого объект преобразуется в структуру, поддерживаемую параметрической системой nanoCAD, и добавляется в текущую базу чертежа.

## Параметрическая модель

Основная идея проекта заключается в том, что геометрия не задаётся только фиксированными числовыми значениями.

Например, высота ножки определяется выражением:

```text
Высота ножки =
Высота стола − Толщина столешницы
```

Положение ножки может зависеть от:

```text
Координата точки вставки
+ размер столешницы
+ отступ ножки
```

Поэтому при изменении размеров столешницы связанные элементы автоматически пересчитываются.

---

## Пример параметрических зависимостей

Для столешницы:

```text
LengthTop
    ↓
Длина столешницы
```

```text
WidghtTop
    ↓
Ширина столешницы
```

```text
ThickTop
    ↓
Толщина столешницы
```

Для ножек:

```text
HeighTable
      │
      ├── ThickTop
      │
      ▼
Высота ножки
```

Положение ножек:

```text
PointX + LengthTop + TableLegCrossX
PointY + WidghtTop  + TableLegCrossY
```

Таким образом, изменение одного параметра может влиять сразу на несколько геометрических элементов.

## Использование

1. Запустить команду:

NSC_TABLE
